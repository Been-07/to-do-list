# ✅ To-Do List Manager

A command-line To-Do List application with priority levels, dual‑format storage (CSV / JSON), and automatic saving. Built with Python OOP.

## ✨ Features

- ✅ Add new tasks with name, description, and priority (low/medium/high)
- ✅ Remove tasks by number
- ✅ View all tasks with clear formatting
- ✅ Choose storage format: **CSV** or **JSON** (changeable at runtime)
- ✅ Auto‑save after every change – data never lost
- ✅ Auto‑load existing data on startup
- ✅ Handles missing files gracefully
- ✅ Simple, intuitive menu interface

## 🛠️ Technologies

- Python 3
- `csv` module (standard library)
- `json` module (standard library)

## 📦 Installation

```bash
# No external packages required – only Python 3
git clone https://github.com/Been-07/to-do-list.git
cd to-do-list
```
